# Nikita Chistyakov — Portfolio

Personal portfolio site for Nikita Chistyakov, Senior Analytics Engineer.

Built with [Astro](https://astro.build) 7 and [Tailwind CSS](https://tailwindcss.com) v4, deployed as a static site on [Vercel](https://vercel.com).

## Development

```bash
npm install
npm run dev
```

Site runs at `http://localhost:4321`.

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` auto-deploy via Vercel's zero-config static Astro detection — no manual configuration needed.

## Content

All copy (contact info, about, experience, education, skills, projects) lives in `src/data/profile.ts` as the single source of truth. Edit there to update site text.
